# Tribulation Radio Music

This folder is the station's main music rotation.

## Add Music

Upload MP3, WAV, OGG, M4A, FLAC, or AAC files into this folder.

The station automatically watches the music library and can start the station when audio becomes available.

## Temporary Test Music

The project can use original temporary test tracks while the permanent station music library is being built.

Recommended naming format:

- `Tribulation_Radio_Keep_the_Faith.mp3`
- `Tribulation_Radio_Never_Alone.mp3`
- `Tribulation_Radio_Rise_Again.mp3`

Keep production audio files in the hosting server's `music/` directory when they are too large for normal source-control workflows. Do not commit copyrighted music unless you have permission to distribute it.
